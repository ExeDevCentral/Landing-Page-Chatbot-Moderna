## ⚡ Core Capabilities

- **AI Conversational Agent:** Embedded chat interface delivering context-aware answers and customer triage.
- **Enterprise Ticket Management:** Validated customer issue submission with auto-retry mechanisms, exponential backoff, and state tracking.
- **n8n Webhook Triggers:** Seamless webhook dispatches to orchestrate notifications (Slack, Email, CRM).
- **Hardened Security Architecture:** Rate limiting, Helmet security headers, CORS origin enforcement, and Jest verification suites.

## 🚀 Quickstart & Setup

```bash
# Clone the repository
git clone https://github.com/ExeDevCentral/Landing-Page-Chatbot-Moderna.git
cd Landing-Page-Chatbot-Moderna

# Install dependencies
npm install

# Start server and frontend
npm run dev
```
